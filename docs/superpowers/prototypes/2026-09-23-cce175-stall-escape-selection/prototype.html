A driveable model of one night of the engineering-docs-agent pipeline. Press buttons, watch the baseline move — or fail to.

The question this answers

The docs pipeline documents merged pull requests oldest-first and keeps a baseline marking how far it has got. A PR whose page could not be written is held back, and the baseline may not move past it — so one stuck PR stops everything behind it.

A safety valve exists: if the baseline has not moved in four days, the pipeline forgives a stuck PR — abandoning its documentation permanently so the rest can proceed. The question is which one. Forgive too eagerly and work is thrown away that was never even attempted. Forgive too cautiously and the pipeline freezes silently, which is what happened for 31 days.
